# NextCampaign
Note: This code is vibe coded and may not be the most efficient or well-written code. It is a work in progress.

NextCampaign is an Openplanet plugin for Trackmania that displays a countdown to the next official campaign directly on the game's start screen. It helps players stay informed about upcoming seasons and campaign releases.

## Features

- **Start Screen Overlay**: Displays relevant campaign information only on the main menu, keeping the gameplay UI clean.
- **Accurate Countdown**: Shows time remaining in months, days, hours, and minutes, using calendar-aware calculations.
- **Release Date Details**: Displays the exact release date and time of the next campaign.
- **Interactive Link**: Includes a direct, clickable link to [nextcampaign.m8.no](https://nextcampaign.m8.no/) for more details.
- **Customizable Visibility**:
  - Toggle the entire overlay on or off.
  - Option to hide the overlay when the Openplanet UI (F3) is closed.
  - Toggle the window titlebar for a cleaner look.
- **User-Movable UI**: The overlay position can be customized by dragging it.

## Installation

1. Ensure you have [Openplanet](https://openplanet.dev/) installed for Trackmania.
2. Enable developer mode in the Openplanet menu.
3. Download or clone this repository.
4. Copy the `nextcampaign` folder into your Openplanet `Plugins` directory:
   - Typically: `C:\Users\<YourUser>\OpenplanetNext\Plugins\NextCampaign`
5. Refresh your plugins in the Openplanet menu.
